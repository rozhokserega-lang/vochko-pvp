# ВОЧКО МОБА — экспериментальный JS-движок способностей и бот с прогнозом

`abilities-engine.js` — экспериментальное разрешение 20 стихийных способностей, временных статусов и контрстихий. `monte-carlo-bot.js` — поиск среди случайно сгенерированных допустимых раскладок, оценка на два раунда через моделирование нескольких ответов соперника. `tournament.js` — парный турнир с перестановкой сторон.

Запуск: `node --test` и `node tournament.js 30` (60 партий).

## Ограничения

- Файлы `engine.js`, `elements.js`, `combos.js`, `cards.js` в архиве — локальные совместимые копии ключевых формул для тестов; для интеграции в репозиторий следует использовать оригинальные модули проекта и провести интеграционные тесты.
- Это не точный MCTS и не оценка математической вероятности победы. Два раунда моделируются эвристически; последующие руки случайные.
- Нынешние контрстихии заданы концептуально; точные правила при столкновении атаки/защиты, статусов, лечения, поджога и пробития требуют окончательного согласования.
- Механики могут отличаться от производственного `resolveRound` (порядок отражения, урона по Нексусу, перехода между целями и статусов). Не подключать к сетевой игре без синхронизации серверного движка и клиента.
- Турнир сравнивает нового бота с упрощённым жадным генератором пар, **не** с текущим `shared/bot.js`; его результаты не доказывают превосходство над производственным ботом.
