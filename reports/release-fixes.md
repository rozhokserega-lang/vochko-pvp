# Исправления релизного аудита и общие подсказки построек

Исправления выполнены поверх `28d8a688a59d89067e5f35defbf42322d534a156`, отдельная ветка `fix/release-audit-status-inspector`. Изменения не развёрнуты в production и не слиты в main.

## Изменения

- **F01** — восстановлены импорты create-room. Фикстура теперь выполняет все шесть настоящих Edge handlers, инжектируя только реально импортированные имена: отсутствие импорта больше не маскируется.
- **F02** — join сохраняет rules/seed; вход существующего участника идемпотентен, включая владельца и PvE. Чужое занятое место не отдаётся.
- **F03** — после фазы статусов фиксируются цели всех линий на весь бой. Сначала основные удары, затем агрегированные ответки/разряды/лечение по тем же целям, без перехода на следующую постройку посреди боя. Лечение не воскрешает постройки. Процент Нексуса по-прежнему фиксируется до статусов. Воспроизведение из аудита теперь оставляет внутреннюю башню 18 HP при обоих порядках мест.
- **F04** — единый StatusBadges renderer для своих/вражеских башен, этажей и самого Нексуса. Всплывающая карточка вынесена в body и не обрезается ареной: портрет, название/сторона/линия, HP, все статусы, сила, время, длительность, источник и противодействие. Работают hover, фокус, нажатие, Escape, закрытие снаружи. На телефоне можно читать карточку и отдельно убрать свои поставленные карты.
- **F05** — бот автоматически принимает реванш; rules/AI/seed/режим раздачи переносятся; повторный запрос возвращает уже созданный матч.
- **F06** — восстановление по сохранённому ID/коду использует идемпотентный вход участника. Сервер возвращает только собственную принятую раскладку для восстановления заблокированного хода; нераскрытые карты противника не возвращаются.
- **F07** — новые матчи получают version=2 и dealMode=random. У старых матчей без dealMode остаётся balanced (7/7). Текущая рука не меняется при get-state или повторном входе.
- **F08** — исправлен знак оценки пробитых внутренних башен в AI. Исправлена дедупликация вариантов с разными ролями одинаковых четырёх карт. AI моделирует нужный режим раздачи, способности, варианты и ablation; случайные потоки симуляции привязаны к моделируемой стороне. Записывается число действительно оценённых кандидатов.
- **F09** — отмена очищения Грозой записывается один раз. Есть числовой тест: Гроза другой линии не мешает; на той же линии горение тикает и гаснет.
- **F10** — описания и предварительная сила пары учитывают выбранный баланс и публичные собственные статусы. Вода снимает 2 брони в рекомендованном варианте. Правильно названа контрстихия Грозы — Земля. Неизвестная защита врага не используется. Горение/начальное лечение показываются до основной атаки; чистое лечение не выглядит потерей HP.
- **F11** — Realtime дополняется загрузкой при SUBSCRIBED, online/focus/visibility и резервным опросом; запросы сериализуются, обработчики снимаются при выходе. Неизменившаяся версия не перерисовывает сцену. connected учитывает leftSeat, возврат участника снимает отметку выхода.
- **F12** — исторические отчёты отмечены как устаревшие; исправлена ошибочная вероятность двух тузов (29,109%). Все способности пишут события реального эффекта, турнир дедуплицирует многокомпонентные активации. Добавлен отдельный физический победитель места в CSV. Турниры по умолчанию используют фиксированный объём работы вместо зависимости от скорости машины; зеркальная проверка использует раздельные потоки раздач, планирования и удачи каждой игровой идентичности. Полная повторная балансировка 15 000 партий ещё не выполнена: старые win rate не выдаются за результаты исправленной версии.

## Локальный просмотр

`npm ci`, затем `npm run dev:preview` → http://127.0.0.1:5191/ . Локальные матчи живут в памяти до перезапуска процесса. Production Edge Functions нужно обновлять отдельным согласованным выпуском всего комплекта; публикация только фронтенда не включает исправления серверного движка.

## Устойчивый локальный запуск

`npm run dev:background` запускает preview отдельной группой процессов и проверяет ответ сервера; закрытие вызывающего терминала не посылает ему сигнал завершения. Логи и PID — в игнорируемом `.local-preview/`. Перед повторным запуском проверяется уже работающая игра. Прямой `dev:preview` остаётся доступен для отладки. При потере связи локальный клиент выводит понятное сообщение вместо сырого Failed to fetch.
