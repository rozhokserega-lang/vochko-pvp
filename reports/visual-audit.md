## 1. Стек и архитектура

- **Сборка:** Vite 8, vanilla JS (без фреймворков), GitHub Pages (статика) + Supabase (авторитетный сервер).
- **Вход:** `index.html` содержит только `<div id="app">` — все экраны генерируются JS.
- **Поток экранов** (`src/main.js`): `boot()` → `renderLobby()` (`src/ui/Lobby.js`, класс `.fortress-root`)
  → `waitingRoom()` (та же `Lobby.js`) → `enterMatch()` → `render()` (`.match-screen`:
  header + `#nexusScore` + `.battle#lanes` из `src/ui/arena/ArenaScene.js` + `#hand` из
  `src/ui/card-panel/CardPanel.js`) → `EndScreen.js`.
- **Стили:** 11 CSS-файлов, импорт в `main.js` и `Lobby.js`. Активные: `styles.css`,
  `combat-v5.css`, `arena/arena.css`, `arena/tower-crystal.css`, `arena/nexus-crystal.css`,
  `arena/attack-charge.css`, `arena/status-badges.css`, `arena/ability-feed.css`,
  `card-panel/card-panel.css`, `ui/fortress.css` (лобби). **Не импортируется:** `arena-v19.css` (523 строки, легаси).
- **Ресурсы:** арена v20 — `src/ui/arena/assets/` (фон, 6 состояний башен ally/enemy
  full/damaged/ruins, 2 Нексуса, 11 анимаций стихий, 5 gif-исходников для теста прозрачности),
  инлайновые base64-копии в `arena/arena-assets.js`; панель руки `card-panel/assets/panel-unified.png`
  (2172×724) + кнопка «Готово» (2 состояния); лобби — инлайновый hero-арт в `fortress.css`,
  10 столовых webp стихий в `menu-assets/`. **PNG-файла логотипа в репозитории нет** —
  логотип вшит в hero-арт лобби; в матче и комнате ожидания бренд только текстовый.
- **PvP-комнаты:** Edge Functions (`create-room`, `join-room`, `get-state`, `submit-turn`,
  `rematch`, `leave-room`), realtime-уведомления `{matchId,version}` + `get-state`.
  Локальный стенд `scripts/dev-local.mjs` (порт 5185, in-memory SQL) — использован для аудита.
- **Тесты:** `npm test` (node --test, 10 файлов: движок + UI-контракты `v19-ui/arena-ui/status-ui/transparency`),
  Playwright-прогоны `browser-local/browser-elements/browser-nexus/browser-v19/browser-final-round`.
  Тесты завязаны на селекторы: `[data-act="create|bot|exit"]`, `.code`, `[data-open="join"]`,
  `#roomInput`, `#joinRoomButton`, `#hand .card`, `.tower.drop-target[data-lane][data-kind]`,
  `#fightBtn`, `#roundBadge`, `#panelPower` (точный текст пары), `#panelEffect`,
  `.combat-card-reveal`, `#phase` (текст «Атака по щитам»), `.end-overlay.show`,
  `nexus-fortress nexus`, `tower-hp tower-meter tower-crystal` и др. — при визуальных
  изменениях эти контракты сохранены.

## 2. Что уже сделано хорошо (не трогаем механику)

- Игровое поле v20: спрайтовые башни 3 состояний × 2 команды, большие Нексусы
  с этажами, рубиновые HP-кристаллы с золотой оправой, циановые щиты,
  хореография боя v19 (раскрытие атак → щит → HP → финиш) с дедупликацией по
  номеру отчёта (`combat-logic.js`) — повторный Realtime не переигрывает анимации.
- Панель руки: единый арт, зона-предпросмотр пары в «сфере», карман силы, раздача
  с задержкой, drag&drop указателем (мышь + тач), тап-выбор пары.
- Лобби: полноценный фэнтезийный hero с логотипом, стеклянное меню, сетка стихий
  с переключателем анимаций, калькулятор комбинаций, правила.
- Мобильная адаптация: сцена 1600×900 aspect-fit в контейнерных единицах (cqw/cqh),
  лента руки со скроллом, тап-статусы, `prefers-reduced-motion` почти везде.

## 4. Оценка по экранам (сводка)

- **Главная (лобби):** композиция 8/10, стиль соответствует утверждённому; P2-4.
- **Выбор режима:** тот же лобби-блок — ок; модал входа по коду аккуратный.
- **Создание комнаты:** кнопка есть, но экран ожидания — провал (P0-1).
- **Комната ожидания:** 2/10 — см. P0-1, P1-4.
- **Игровое поле:** 8/10 — сильная сцена, но P0-2, P0-3, P0-4, P1-1, P1-5.
- **Экран результатов:** 5/10 — P1-2.
- **Всплывающие окна/подсказки:** тултипы Нексуса и статус-панели хорошие; P1-5, P2-5.
- **Мобильный интерфейс:** базово рабочий (нет горизонтального скролла, drag не конфликтует
  со скроллом — `touch-action` настроены), но P0-3, P1-3; проверено 320/375/390/430/768.

## 5. План изменений (Этапы 3–8 ТЗ)

1. **Единые токены** в `styles.css` (золото/панель/линия/текст) + применение в шапке матча, финале, комнате ожидания.
2. **Комната ожидания** в fortress-стиле: фон-сцена, логотип-надпись, центральная панель, синяя рамка «Вы», красная рамка «Соперник», значок VS, большой код с кнопкой копирования, кнопка-ссылка, «Ждём соперника» с анимацией, выход. Серверные обработчики не трогаем; селекторы `.code`, `[data-act="exit"]`, `data-info="match"` сохранены.
3. **Полоса фазы матча**: стилизованный золотой бар `⚔ ПРОТИВ · <#phase>` (id сохранён для хореографии и тестов).
4. **Карман силы**: нейтральный плейсхолдер «Выбери две карты», вместо пустой чёрной рамки.
5. **Мобильная читаемость HP**: container-queries — компактнее подписи/отступы кристаллов на узких сценах; бейджи линий не перекрываются.
6. **Шапка матча и финальный экран** в общем стиле (рамки, градиенты, иконки).
7. Мелкие фиксы: scoping `overflow-y:auto`, полировка `#status`.

Всё — только CSS/разметка представления; игровые правила, движок, submit-turn, realtime, обработчики комнат не изменяются.
