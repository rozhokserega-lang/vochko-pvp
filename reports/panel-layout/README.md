# Панель не перекрывает нижний ряд

После увеличения башен на 18 HP уменьшено перекрытие поля панелью: с 14% до 7,5% ширины сцены. Сфера опустилась к нижней стене, а расчёт масштаба игрового экрана учитывает новую общую высоту.

`npm run test:panel` открывает настоящий локальный матч с ботом и проверяет четыре размера окна: 1280×900, 1100×700, 844×390, 390×844. Сфера находится ниже оснований обеих башен нижнего ряда с каждой стороны; карты, кнопка готовности и карман показателей помещаются по высоте, горизонтальной прокрутки нет. Ошибок JavaScript нет.
