# VOCHKO MOBA — отчёт о визуальном улучшении (Этап 11)

Дата: 2026-11-14 · Ветка: `feature/visual-upgrade` (создана от актуальной рабочей ветки
`feature/random-deal-status-tooltips`). Merge в `main` не выполнялся.

Аудит: `reports/visual-audit.md` · Скриншоты: `reports/screenshots/before/` и `after/`
(сняты скриптом `tests/.shots/visual-audit-shots.mjs` на локальном стенде

## 1. Обнаруженные проблемы (итог аудита)

**P0**
1. **Комната ожидания** — не использован утверждённый фэнтезийный стиль: голая тёмная карточка на пустом фоне, без фона/логотипа/рамок игроков/VS, сырой UUID внизу, нет кнопок копирования приглашения.
2. **Полоса фазы матча** рендерилась без стилей (`⚔ ПРОТИВРаскладка` слеплены) — стили `.nexus-phase` остались только в неиспользуемом легаси-файле `arena-v19.css`.
3. **Мобильная нечитаемость HP (320–430 px)** — подписи «12 / 12» центральных башен налезали друг на друга и упирались в бейдж линии.
4. **Пустой чёрный карман силы** (`#panelPower`) внизу панели руки при невыбранной паре выглядел как артефакт.

**P1**
5. Шапка матча вне стиля игры (плоский текст, «розовая» кнопка выхода).
6. Финальный экран минималистичный, без рамок/иерархии кнопок.
7. На мобильных ширинах бейджи линий упирались в HP-подписи.
8. Приглашение в комнату не выделялось, копирование отсутствовало.

**P2**
9. Токены разъехались (`styles.css :root` vs `fortress.css`, три redefine `--gold`).
10. `arena.css` глобально переоткрывал `body{overflow-y:auto}` (утечка debug-стилей в обычный матч).
11. Мёртвый груз (`arena-v19.css`, `Board.js`+`assets.js`, `PairPreview.js`, `Placement.js`, `panel.png`) — зафиксирован как кандидат на отдельную чистку, **в этой ветке не удалялся**.

## 2. Реализованные улучшения

- **Комната ожидания (Этап 6 ТЗ)** — полный redesign в утверждённом стиле:
  фон-сцена (утверждённый арт арены `bg.webp`, приглушён), логотип-надпись
  «⚔ ВОЧКО МОБА» с золотым градиентом, центральная панель с двойной золотой
  окантовкой, **синяя рамка игрока** («ВЫ · Синяя сторона»), **красная рамка соперника**
  («СОПЕРНИК · ждёт…» с анимированными точками), **значок VS**, панель кода
  (`КОД КОМНАТЫ` + крупный код + кнопка «⧉ Скопировать код»), панель ссылки-приглашения
  с кнопкой копирования (Clipboard API + fallback `execCommand`, фидбек «✓ Скопировано»),
  статус «⏳ Ждём второго игрока…» с пульсом, кнопка отмены. Серверные обработчики
  комнат не тронуты; приглашение по ссылке/коду, отмена и автозапуск сохранены.
  Дополнительно: повторное `get-state` больше не перерисовывает экран (та же комната →
  skip), поэтому пульс не перезапускается каждые 800 мс.
- **Полоса фазы** — стилизованный золотой пилюль-бар `⚔ ПРОТИВ · РАСКЛАДКА`
  (id `#phase` и текстовые состояния хореографии сохранены — тесты `#phase` зелёные).
- **Карман силы** — вместо пустого кармана подсказка «Выбери две карты» (при выборе
  пары значения 🛡/⚔ и название стихии работают как раньше; точный контракт теста
  `#panelPower` сохранён).
- **Читаемость HP на мобильных** — container-queries в `tower-crystal.css`:
  компактные подписи/отступы кристаллов на сценах ≤700 px и ≤380 px (scaleX .92,
  letter-spacing) — измерено Playwright-пробником: зазор между «12/12» 3–11 px вместо
  наложения; бейдж линии опущен на узких сценах (`translate(-50%,-38%)`).
- **Шапка матча** — тёмно-синяя полоса с золотым градиентным заголовком; кнопка выхода без изменений по смыслу.
- **Финальный экран** — тёмно-синий градиентный диалог с золотой окантовкой, золотой заголовок, иерархия кнопок (золотой «Реванш», приглушённый «Выйти»).
- **Унифицированные токены** — расширен `:root` (`--gold-bright/--gold-soft/--gold-deep/--panel-navy/--ally/--enemy/--frame-gold` и т.д.), новые стили используют токены.
- **Debug-утечка** — `body{overflow-y:auto}` теперь `body:has(.arena-debug-panel)` (страницы `?arenaDebug=1` и `?panelDebug=1` сохранили прокрутку).
- **`prefers-reduced-motion`** — добавлен для новых анимаций (точки ожидания).

Игровая механика, баланс, серверная логика PvP и правила боя **не изменялись**:
изменены только представления (`Lobby.js` — разметка экрана ожидания, `CardPanel.js` —
подсказка пустого кармана) и CSS.

## 4. Графические ресурсы

Использованы только существующие утверждённые ресурсы: `src/ui/arena/assets/bg.webp`
(фон комнаты ожидания, уже инлайнён в бандле через `arena-assets.js` — сетевого
довеса нет). Новых изображений не добавлялось; ни один ресурс не удалён.

**Не хватает (в списке нужных, подменять нечем):** отдельный PNG логотипа
«ВОЧКО МОБА» для тёмных фонов (сейчас логотип вшит в hero-арт лобби; в комнате
ожидания и шапке матча — текстовая стилизация). Если появится файл — можно заменить
`.waiting-logo` и `h1` шапки без изменения разметки.

## 5. Анимации

Новые (только CSS, transform/opacity): пульс точек «Ждём…» (`waitingDots`), фидбек
кнопок копирования. Существующая боевая хореография v19/v20 не менялась и
проверена живым прогоном полного матча с ботом (раскрытие атак → щиты → HP →
финиш, 7 раундов, ни одной JS-ошибки). Дедупликация по номеру отчёта и guard
комнаты ожидания исключают повторное воспроизведение при refresh/реконнекте.

## 6. Мобильные улучшения (320/375/390/430/768)

- HP и бейджи линий больше не перекрываются (проверено прямоугольниками DOM на 320/390/430/1440).
- Нет горизонтальной прокрутки (проверено `scrollWidth ≤ clientWidth` на 320–430, лобби и матч, комната ожидания).
- Комната ожидания адаптивна: игрок-рамки → колонка, код масштабируется `clamp()`.
- Кнопки копирования ≥36 px, работают тапом; подсказки (`#status`) не выходят за экран.
- Drag&drop и скролл ленты руки не конфликтуют (`touch-action` сохранены).

## 8. Известные ограничения

1. На портретных экранах вокруг сцены остаётся «воздух» — это следствие фиксированного
   аспекта арены 1600×900 (изменение потребовало бы пересмотра раскладки поля).
2. Логотип в комнате ожидания/шапке — текстовая стилизация (PNG нет, см. §4).
3. Легаси-файлы не удалены (см. §1 P2-11) — отдельная задача.
4. `tests/browser-final-round.mjs` и `browser-v19.mjs` (проверка деплоя) требуют
   сборки/деплоя — не запусквались локально.
