## 2. Исправленные ошибки аудита

### 2.1. Баг методологии турнира: дублирующиеся зеркальные партии (Этап 2)

**Симптом**: `mulberry32(seed + 0.5)` — дробная часть отсекается `>>> 0`,
поэтому партия со сменой сторон получала **тот же сид**, что и прямая.
**Следствие**: «1000 игр» были 500 уникальных позиций + 500 их зеркальных
дубликатов; идеальная симметрия old-old (454/454) — частично артефакт
парного зеркала; статистическая мощность завышена вдвое.

**Исправление**: `shared/seeds.js` — `gameSeed(base, i) = (base + [i/2]) * 2 +
(swap?1:0)` — непересекающиеся потоки для каждой партии.

**Регрессионный тест**: `tests/balance-variants.test.js` — «АУДИТ-фикс:
зеркальные партии получают РАЗНЫЕ потоки случайности».

**Следствие для прошлых результатов**: все предыдущие числа считаются
**предварительными** (по требованию задания). Пересчёт: база и 12 вариантов
баланса (Этапы 3–4) и финальные матчапы ×1000 (Этап 5) выполняются на
исправленных сидах; старые файлы сохранены для сравнения.

### 2.2. Уточнения методологии (без ошибок, но зафиксировано)

- Парные сиды в ablation корректны (одинаковые раздачи до первой расходимости
  из-за отключённого эффекта — стандартно).
- Бюджеты времени консистентны внутри сравнений (300 мс для ablation/вариантов,
  500 мс для матчапов); в отчётах указаны.
- Учёт ничьих: `smartWinRate` считается по решённым партиям, доля ничьих
  приводится отдельно.
- Ограничение статистической мощности: 300 игр → ±5.6 п.п. (95% CI);
  1000 игр → ±3.1 п.п. В финальных рекомендациях значимость проверяется
  точным биномиальным ДИ по парным исходам (`scripts/balance-aggregate.mjs`).
