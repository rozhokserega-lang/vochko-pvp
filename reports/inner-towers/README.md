# Новые башни на 18 HP

Использованы все шесть PNG пользователя: синяя и красная башня в целом, повреждённом и разрушенном состоянии. Ресурсы подготовлены в WebP с сохранением прозрачности; [манифест](../../src/ui/arena/assets/inner-towers/manifest.json) содержит исходные имена, SHA-256 и кадрирование. Общий размер — около 798 КиБ.

Новые изображения назначены только внутренним башням с максимальным HP 18. Внешние башни на 12 HP сохраняют прежние изображения и геометрию. Существующие пороги сохранены: 10–18 HP — целая, 1–9 — повреждённая, 0 — руины. Правила боя, урон и колоды не менялись.

Целые и повреждённые башни подготовлены в общей системе координат. Для них откалиброваны два слота карт и центр стихии. Обломки сохраняют естественные пропорции каждого исходника и ту же ось основания. Высота целой/повреждённой башни увеличена с 218 до 240 единиц дизайн-пространства (+10,1%), ширина обломков — с 165 до 182. Размер башен на 12 HP сохранён. Центры рядов опущены с 256/475/679 до 270/510/750: шаг 240 позволяет разместить увеличенные башни без пересечения соседних спрайтов. Редактор раскладки использует геометрию соответствующей модели.

Проверки: 373 автоматических теста прошли; сборка прошла; браузерная проверка `npm run test:towers` проверила обе стороны, все состояния, наложение карт/эффекта, смену изображения при изменении HP и отсутствие горизонтального скролла на телефоне. Регрессионный сценарий `npm run test:core` прошёл.
