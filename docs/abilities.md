# Стихийные способности и статусы (feature/elemental-ai)

## Включение

Способности включаются **флагом матча**: `state.rules.abilities === true`
(создаётся в `create-room`; по умолчанию **вкл** для новых матчей, у матчей,
созданных до обновления, поля нет → работает прежний баланс 1:1).
Движок: `resolveRound(state, turnA, turnB, { abilities: true, rng, disabled })`.

## Порядок раунда (ТЗ)

1. **Фаза статусов** (в начале раунда):
   - Очищение (Вода в защите): снимает `burn/weakenAttack/weakenDefense`
     **до** их применения; если негативов нет — лечение 2 HP текущей цели линии.
   - Тик поджога: урон по текущей цели, поджог гаснет.
   - Применённые статусы стираются (жизненный цикл — 1 раунд).
2. **Защита → атака → расчёт щита → урон**: буст атаки → ослабление атаки →
   ослабление защиты → броня + щит Бури (+4) → модификаторы атакующего
   (Вода −3 брони, Земля ×0.85, Лава ×0.9) → Заслон вихря (×0.9 при горящем
   соседе) → `hit = max(0, atk − def)` → Пар ×0.9 по hit → урон
   (`max(0, atk−def)`, излишек не переносится).
3. **Последствия попадания** (`hit > 0` для «при попадании»-способностей) и
   триггеры защиты (блок → ответный урон Огня/Воздуха; удар врага → ответка
   Лавы, заряд Грозы; блок → лечение Пара).
4. **Перенос статусов** на следующий раунд (накопление через max, капы:
   burn ≤ 5, armor ≤ 9, weaken ≤ 30%, boost ≤ 6).

## Контрстихии — таблица (НЕ утверждённая механика)

Направленные отношения (`COUNTERS`): fire→water, water→thunderstorm,
earth→lava, air→sandstorm, steam→ice, lava→water, fire_vortex→earth,
ice→fire, thunderstorm→earth, sandstorm→water.

**В основном балансе эффекты контрстихий НЕ применяются** (по требованию ТЗ).
Предложение на согласование — три варианта, от мягкого к жёсткому:

1. **Подавление способности** (рекомендуется): если защитная пара линии —
   контрстихия к элементу атакующей пары, атакующая способность этой линии
   не срабатывает (только числовой урон). Симметрично для защитной способности.
2. Подавление + −10% числового урона.
3. Полная нейтрализация удара (не рекомендуется — обесценивает атаки).

Точка внедрения: `effectiveLine()` / `hitConsequences()` уже получают элементы
обеих пар; достаточно включить проверку `isCounter()` и добавить флаг в правила
матча (`state.rules.counters`).

## Прочее

- Статусы видны обеим сторонам (`get-state` → `board.{me,opponent}.statuses`),
  UI: бейджи на башнях (`StatusBadges.js`) и лента срабатываний в хореографии.
- `disabled: [id...]` в resolveRound — для ablation-тестов баланса.
- Случайность (Разряд) — через инъектируемый `rng`; сервер хранит `rngSeed`
  в state, раунды воспроизводимы.
