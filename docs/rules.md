# Правила «Три линии» v1.5 (зафиксированы)

Источник — `legacy_v15.html`; движок `shared/` перенесён 1:1 и покрыт тестами.

## Поле

- 3 линии: ВЕРХ / ЦЕНТР / НИЗ.
- У игрока на каждой линии: внешняя башня **12 HP**, внутренняя **18 HP**.
- Нексус **80 HP**. Порядок урона: внешняя → внутренняя → Нексус.
- **Излишек урона не переносится** на следующую цель.
- Щит Нексуса: **0/40/70/100%** расчётного урона при **0/1/2/3** пробитых
  внутренних башнях. При нуле пробитых линий Нексус неуязвим.
- Лимит **45 раундов**. Оба Нексуса умерли одновременно — ничья;
  при лимите сравнение HP Нексусов.

## Колода и рука

- 52 карты: A=11, J/Q/K=10, числовые по номиналу.
- Каждый раунд: **7 красных (♥♦) + 7 чёрных (♠♣)** каждому игроку, внутри руки
  без дублей; между игроками раздачи независимые — совпадения допустимы.
- 7 красных → 3 пары атаки, 7 чёрных → 3 пары защиты; по карте каждого цвета
  остаётся свободной.
- В паре только одна масть-цвет: ♥+♦ = ♨️ Пар, ♠+♣ = 🌫️ Буря; красная+чёрная запрещена.

## Комбинации (строгий приоритет, не складываются)

1. A+A ×2.5
2. K+Q одной масти ×2.0
3. A + карта стоимостью 10 ×1.8
4. Одинаковый номинал ×1.6
5. Одна масть ×1.4
6. Соседние значения ×1.2
7. Иначе ×1.0

Сила пары = `round((v1+v2) × множитель)`.

## Стихии

- ♥♥ 🔥 Огонь · ♦♦ 💧 Вода · ♠♠ 🪨 Земля · ♣♣ 🌪️ Воздух · ♥♦ ♨️ Пар · ♠♣ 🌫️ Буря.
- Атака: Огонь>Воздух ×1.0975; Огонь>Земля ×0.9025; Вода>Земля ×1.0975; Вода>Воздух ×0.9025 (округление после множителя).
- Защита: Земля ×1.12; Воздух ×1.05; Буря ×1.052; Вода-атака → ×0.85; Пар-атака → ×0.925; Воздух против Воды/Пара → ×1.08. Округления каскадом.
- Урон: `max(0, атака − защита)`.
- Поджог: Огонь **4**, Пар **2** при положительном уроне; против Земли/Воздуха кап до 1. Применяется в начале следующего раунда до прямого урона, через башню не переносится.

## Укрепление

- Один раз за матч, выбирается линия **до** разрешения раунда.
- На этой линии: своя защита ×1.25, своя атака ×0.85 (округления; при hit=0 поджог гаснет).
- Симметрично для обоих игроков (ADR-5). После разрешения раунда — сгорает.
