# Правила «Три линии»: 10 стихий

Источник актуального баланса — `shared/elements.js`; карточные множители и правила здоровья сохранены.

## Поле

- 3 линии: ВЕРХ / ЦЕНТР / НИЗ.
- У игрока на каждой линии: внешняя башня **12 HP**, внутренняя **18 HP**.
- Нексус **80 HP**. Порядок урона: внешняя → внутренняя → Нексус.
- **Излишек урона не переносится** на следующую цель.
- Щит Нексуса: **0/40/70/100%** расчётного урона при **0/1/2/3** пробитых
  внутренних башнях. При нуле пробитых линий Нексус неуязвим.
- Лимит **45 раундов**. Оба Нексуса умерли одновременно — ничья;
  при лимите сравнение HP Нексусов.

## Колода и рука

- 52 карты: A=11, J/Q/K=10, числовые по номиналу.
- Каждый раунд: **7 красных (♥♦) + 7 чёрных (♠♣)** каждому игроку, внутри руки
  без дублей; между игроками раздачи независимые — совпадения допустимы.
- По атакующей и защитной паре на каждой линии: всего 12 карт, любые две остаются свободными.
- Любые две масти можно сочетать. Атакующая пара даёт только атаку, защитная — только защиту.

## Комбинации (строгий приоритет, не складываются)

1. A+A ×2.5
2. K+Q одной масти ×2.0
3. A + карта стоимостью 10 ×1.8
4. Одинаковый номинал ×1.6
5. Одна масть ×1.4
6. Соседние значения ×1.2
7. Иначе ×1.0

Сила пары = `round((v1+v2) × множитель)`.

## Стихии

| ID | Масти | Стихия | Атака | Защита |
|---|---|---|---|---|
| fire | ♥♥ | Огонь | +20% | −10% |
| water | ♦♦ | Вода | +10% | +10% |
| earth | ♠♠ | Земля | −5% | +25% |
| air | ♣♣ | Воздух | +5% | +15% |
| steam | ♥♦ | Пар | +10% | +10% |
| lava | ♥♠ | Лава | +20% | −5% |
| fire_vortex | ♥♣ | Огненный вихрь | +15% | 0% |
| ice | ♦♠ | Лёд | 0% | +20% |
| thunderstorm | ♦♣ | Гроза | +15% | +5% |
| sandstorm | ♠♣ | Песчаная буря | +5% | +15% |

Порядок мастей не влияет на стихию. Для каждой пары отдельно:

`basePower = Math.round((v1 + v2) * multiplier)`

`attack = Math.round(basePower * (1 + attackBonus / 100))`

`defense = Math.round(basePower * (1 + defenseBonus / 100))`

Атака линии — показатель attack атакующей пары; защита линии — показатель defense защитной пары. Пара в атаке не увеличивает свой щит, пара в защите не наносит урон.
В каждую сторону одновременно наносится `max(0, атака линии − защита линии соперника)`.
Процент урона Нексусу фиксируется по числу пробитых линий на начало раунда; новые прорывы влияют на него со следующего раунда. Победитель определяется после всех ударов, поэтому гибель Нексуса не отменяет ответный удар.
Поджог, лечение, заморозка, отражение, дополнительные атаки и контрстихии отключены.
